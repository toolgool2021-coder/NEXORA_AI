# NEXORA AI 2.0

Справочный ассистент экосистемы NEXORA. Автор: [@Toolgool](https://t.me/Toolgool).

Сайт: https://tlnexora-ai.duckdns.org/

## Возможности

- Современный адаптивный тёмный интерфейс, сообщения в свободной форме.
- Распознавание типовых вопросов по ключевым словам и вариантам формулировок.
- Быстрые вопросы с поиском, подсказки по продолжению беседы.
- История сообщений в localStorage текущего браузера, очистка по кнопке.
- Копирование ответов, безопасный вывод текста и ссылок.
- Ответы из встроенной базы в `responses.js`.

**Важно:** это локальный справочный движок с готовыми ответами, а не подключённая генеративная модель. В этой версии нет доступа к интернету, API LLM, автоматического анализа произвольного кода или серверного хранения переписки. Не публикуйте секреты в клиентском JavaScript.

## Файлы

`index.html` — структура интерфейса, `styles.css` — оформление, `script.js` — поиск ответов и чат, `responses.js` — база знаний, `icon.svg` — векторная иконка, `CNAME` — домен GitHub Pages.

`assets/brain.png` оставлен для совместимости со старой версией, но новым дизайном не используется.

## Редактирование базы

Добавляйте запись в объект `DIALOGS` внутри `responses.js`, например:

```javascript
my_topic: {
  text: "Ответ на вопрос.",
  options: ["Ещё вопрос | about", "Назад | main"]
}
```

Для распознавания свободных формулировок дополните объект `aliases` в `script.js` ключом `my_topic` и несколькими выражениями пользователя.

## Приватность

Чат сохраняется только в локальном хранилище браузера посетителя и не отправляется на сервер. Пользователь может удалить данные кнопкой очистки истории. Для чувствительных разговоров рекомендуем не вводить персональные данные.

## Развёртывание

Разместите файлы в корне GitHub Pages. Пользовательский домен указан в `CNAME`; DNS-запись DuckDNS должна быть настроена отдельно. Проверьте HTTPS в настройках репозитория.
